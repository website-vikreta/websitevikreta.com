# The Rubber Duck

If you are reading this file, you are stuck on a bug and have started
opening random markdown files in the repo looking for answers.

That's fine. That's what the duck is for.

Explain the bug to the duck, out loud, one line at a time, like it
has never seen code before. By the time you reach the part where you
say "and then obviously it just—" you will have found it.






The duck has fixed more bugs than any of us. The duck does not get
credit in the commit message. The duck is fine with that.
